# COVID-19-A-DATA-STORY
# 🌍 How COVID-19 Changed the World: A Data Story

> A narrative-driven Streamlit application that guides users through four years of global pandemic data — from the first outbreak to the vaccine revolution.

---

## ✨ What This Is

This is **not** a dashboard. It is a **data story** — a guided, chapter-by-chapter journey through the COVID-19 pandemic using interactive visualisations, animated charts, choropleth maps, and insight boxes that explain what the data means.

Built with `Streamlit`, `Plotly`, `Pandas`, and `NumPy`.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/covid-data-story.git
cd covid-data-story
```

### 2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate        # macOS/Linux
venv\Scripts\activate           # Windows
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Generate the dataset
```bash
python generate_dataset.py
```
This creates `data/covid19_global_data.csv` (~29,000 rows, 20 countries, 2020–2023).

### 5. Launch the app
```bash
streamlit run app.py
```

Open **http://localhost:8501** in your browser.

## 📊 Dataset

The dataset is **simulated** to mirror the epidemiological dynamics of the actual COVID-19 pandemic:

- **20 countries** across 6 continents  
- **Daily records** from 1 January 2020 to 31 December 2023 (~29,000 rows)
- **6 epidemic waves** with Gaussian shapes (Alpha, Beta, Delta, Omicron, BA.2, late-2022)
- **Declining CFR** from 2.5% → 0.8% as treatments and vaccines improved
- **Vaccination rollout** starting January 2021, using logistic growth to a country-specific plateau
- **Sparse random nulls** (~0.5%) to simulate real-world reporting gaps

| Column | Description |
|--------|-------------|
| `date` | Daily timestamp |
| `country` / `iso_code` | Country name and ISO-3 code |
| `continent` | Geographical region |
| `population` | Country population (2020 estimate) |
| `new_cases` / `total_cases` | Daily and cumulative confirmed cases |
| `new_deaths` / `total_deaths` | Daily and cumulative deaths |
| `total_recovered` | Cumulative recoveries |
| `active_cases` | Cases - deaths - recovered |
| `total_vaccinations` | Total vaccine doses administered |
| `people_vaccinated` | People with ≥1 dose |
| `people_fully_vaccinated` | Fully vaccinated individuals |

## 🎨 Design Philosophy

- **Dark editorial aesthetic** — deep navy backgrounds, amber/red/teal accent palette
- **Playfair Display** serif for headings (narrative weight), **Source Sans 3** for body, **JetBrains Mono** for data labels
- **Insight boxes** after every chart — the data never speaks for itself without interpretation
- **Progressive disclosure** — each chapter builds on the last, rewarding sequential reading
- **Animated charts** that play automatically on the Visual Storytelling chapter

## ⚙️ Technical Notes

### Streamlit version
Tested on Streamlit `≥ 1.32`. Earlier versions may not support all Plotly animation features.

### Performance
The dataset is cached with `@st.cache_data`. Initial load takes ~1–2 seconds; subsequent navigation is instant.

### Plotly animations
Animated charts (bar race, scatter race) use Plotly's `animation_frame` parameter. For best performance, use a Chromium-based browser.
